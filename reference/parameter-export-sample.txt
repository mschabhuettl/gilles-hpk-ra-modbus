# Sample LASAL parameter export

This is an example of what the `parameter.txt` file looks like when exported via USB
from a Gilles Touch (Allgemeines → Load/Save → Save to USB).

Each line: `<parameter.path>,<current_value>,<unit_descriptor>,...`

The format is:

- Parameter path uses LASAL namespace (e.g., `LSE_KesselPara_Temp1.sKesselSollTag`)
- Values are integers (multiplied by 10 for ÷0.1 scaling, etc.)
- Unit descriptor tells you the scaling: `Temp3_0` = temperature × 10, `Prozent_3_1` = percent × 10

This file is **invaluable** for matching Modbus values to parameter names —
search for the value you see at REG[xx] and you'll often find a unique match.

## Unit descriptors observed

| Descriptor | Meaning |
|---|---|
| `Temp3_0` | Temperature × 10 (display divides by 10 for °C) |
| `Prozent_3_1` | Percent × 10 |
| `1/10%_3_0` | Percent × 10 (1/10 of a percent precision) |
| `Sek_3_0` | Seconds |
| `Zeitsek_3_0_Div10` | Seconds × 10 |
| `ZeitSek4_0_Div10` | Seconds × 10 (4-digit) |
| `Zeitmin_3_0`, `Zeitmin_4_0` | Minutes |
| `ZeitMin_2` | Minutes (2-digit) |
| `ZeitStd_2_0`, `ZeitStd_Kask` | Hours |
| `Digit2_0`, `Digit3_0` | Plain integer (no scaling) |
| `Stk` | Count (Stück) |
| `mS` | Milliseconds |
| (empty) | Boolean (0 or 1) |
